
# DAY 1 — Chatbots & AI Assistants

## Why it matters

Chatbots are the entry point into AI. Once you learn how to communicate effectively with an AI assistant (called **prompting**), the same skill transfers to almost every other AI tool you'll use—image generators, coding assistants, research tools, presentation makers, automation platforms, and more.

The goal of Day 1 is not just learning to "chat" with AI. It is learning **how to collaborate with AI**.

---

# Tool 1 — Claude

## Website

**[https://claude.ai](https://claude.ai)**

---

## Description

**Anthropic Claude** is a conversational AI assistant developed by **Anthropic** that focuses on reasoning, writing, coding, document understanding, and long-context conversations.

Claude is especially known for:

* Extremely natural writing
* Strong reasoning abilities
* Excellent coding assistance
* Ability to understand very large documents
* Project-based workflows
* Built-in Artifacts
* MCP (Model Context Protocol) integrations
* Connectors that allow Claude to work with your external apps

Unlike many chatbots that simply answer questions, Claude is designed to help users work on **large ongoing projects**.

# Core Features

## 1. Natural Conversations

Claude understands conversational language without requiring perfect prompts.

Example:

> Explain blockchain as if I'm 15.

or

> Explain this in simple English.

---

## 2. Massive Context Window

Claude can read hundreds of pages at once.

Examples:

* research papers
* textbooks
* legal contracts
* company documentation
* dissertations
* PDFs
* source code

Instead of uploading files one by one, Claude can reason across all of them simultaneously.

Applications:

* exam preparation
* literature reviews
* comparing reports
* policy analysis

---

## 3. Artifacts

One of Claude's most powerful features.

Artifacts create editable outputs beside the chat instead of burying everything in text.

Claude can generate:

* websites
* HTML pages
* React apps
* Python scripts
* reports
* resumes
* diagrams
* presentations
* interactive calculators
* games

Example:

> Build me a responsive portfolio website.

Claude opens an Artifact that can be edited without scrolling through chat.

---

## 4. Projects

Projects let you create dedicated workspaces.

Inside a Project you can:

* upload reference files
* set permanent instructions
* maintain project memory
* organize conversations

Useful for:

* Thesis writing
* Startup ideas
* Research projects
* Software development
* Job preparation

---

## 5. Project Knowledge

Inside Projects you can upload:

* PDFs
* Word files
* Markdown
* Source code
* Research papers
* Notes

Claude automatically remembers them throughout that Project.

Example:

Upload your lecture notes once.

Then ask:

> Explain Chapter 6.

Claude answers using your uploaded material.

---

## 6. Styles

Claude allows reusable writing styles.

You can create custom styles like:

* Professional
* Friendly
* Academic
* Marketing
* Technical
* Minimalist

Then switch styles instantly.

Example:

Rewrite this email using my "Professional HR" style.

# Hands-on Micro Tasks

## Task 1 — Claude

Ask Claude:

> Explain **[your work or study topic]** like I'm completely new to it, using only 5 bullet points and one real-world analogy.

Examples:

* Neural Networks
* Robotics
* Accounting
* Marketing
* Databases
* Machine Learning

---

## Task 2 — Google Gemini

Paste either:

* an email thread
* a paragraph
* meeting notes

Then ask:

> Rewrite this in a more professional and polite tone while keeping the meaning unchanged.

---

# Home Task

Choose either Claude or Gemini and have a **3-message conversation** about a real problem you're facing this week.

Examples:

* A difficult email you need to write
* Choosing between two job offers
* Understanding a study topic
* Planning your weekly schedule
* Fixing a coding bug
* Preparing for an interview

After the conversation, answer these reflection questions:

1. What problem did you ask the AI to help with?
2. Which response was the most useful?
3. What was one thing the AI misunderstood, assumed incorrectly, or got wrong?
4. How would you improve your prompt to get a better answer next time?

> **Learning Outcome:** By the end of Day 1, learners should be comfortable interacting with AI assistants, understand the strengths of Claude and Gemini, and recognize that effective prompting is the foundation for using more advanced AI tools throughout the rest of the course.
